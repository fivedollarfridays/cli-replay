# Objective

Create `_redact_event()` in `cli_replay/redact.py` — applies replacement list to a `SessionEvent`'s data field, returning a new event with redacted data.

# Implementation Plan

- Add `_redact_event(event, replacements)` to `redact.py`
- Apply each `(old, new)` replacement to `event["data"]` in order
- Return a new `SessionEvent` with modified data, preserving `t` and `type`
- Do not modify event if no replacements match

# Acceptance Criteria

- [x] Returns new SessionEvent with redacted data field
- [x] Preserves `t` and `type` fields unchanged
- [x] Applies replacements in order (longest first)
- [x] Handles event data containing ANSI escape sequences without breaking them
- [x] No-op when no replacements match
- [x] Tests cover: username in prompt, path replacement, hostname, no-match, ANSI-embedded
