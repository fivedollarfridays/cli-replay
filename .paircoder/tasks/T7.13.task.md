# Objective

Add a `cc_version` field to the process config YAML for pinning the Claude Code version used during recording. Create a changelog document that tracks which CC version produced which recordings.

# Acceptance Criteria

- [ ] Process config YAML schema accepts a `cc_version` field (string)
- [ ] Preflight checks `claude --version` against the pinned `cc_version` from config
- [ ] If version does not match, preflight fails with a clear message showing expected vs actual version
- [ ] `~/test-store/production/CC_CHANGELOG.md` is created with a template documenting version-to-recording mappings
- [ ] Changelog format includes: CC version, date, recording filenames, notes
- [ ] Tests verify config parsing accepts `cc_version` field
- [ ] Tests verify preflight fails on version mismatch
- [ ] Tests verify preflight passes when version matches

# Dependencies

None (config + docs change)
