# Objective

Implement core stitching logic in `cli_replay/process.py`. For each event:
- **In CC range**: strip DA terminal queries only (`\x1b[>0q`, `\x1b[c`) — preserves all TUI content
- **Outside CC range (shell)**: full PII redaction + terminal scrub (colored digit counter, DA queries, title escapes)

Events are never dropped — only their data is cleaned.

## Processing Rules

### Shell sections
- Output events: apply `_build_replacements()` PII substitutions + `scrub_data()`
- Input events: apply PII substitutions only (typed commands may contain paths/usernames)

### CC sections
- Output events: strip DA terminal queries only (`\x1b[>0q|\x1b[c`)
- Input events: pass through unchanged

# Acceptance Criteria

- [ ] `process_shell_event(event, replacements, da_re) -> SessionEvent` applies PII + scrub to output; PII only to input
- [ ] `process_cc_event(event, da_re) -> SessionEvent` strips DA queries from output; input unchanged
- [ ] `process_recording(filepath, config, output)` reads header + events, routes to correct processor, writes output
- [ ] Shell output events have no PII after processing
- [ ] CC output events preserve non-DA content
- [ ] All tests pass with 100% coverage of new code
