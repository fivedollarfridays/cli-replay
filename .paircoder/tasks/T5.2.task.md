# Objective

Update `~/test-store/video3-reset.sh` to call `video3-preflight.sh` after the git reset and exit with a clear error if any check fails. Currently the script exits silently regardless of whether the repo is actually clean.

# Implementation Plan

Add after the `git reset --hard demo-planned` line in `video3-reset.sh`:

```bash
echo "=== Running preflight checks ==="
bash video3-preflight.sh
if [ $? -ne 0 ]; then
    echo ""
    echo "❌ Reset failed — repo is not in a clean demo state"
    echo "   Fix the issues above before recording."
    exit 1
fi
echo ""
echo "✅ Ready to record"
```

Then commit and re-tag `demo-planned`.

# Acceptance Criteria

- [ ] `bash video3-reset.sh` prints "✅ Ready to record" after a clean reset
- [ ] If `video3-preflight.sh` returns non-zero, reset script exits 1 with "❌ Reset failed" message
- [ ] The preflight output (which check failed) is visible before the error message
- [ ] Updated `video3-reset.sh` committed and `demo-planned` tag updated
