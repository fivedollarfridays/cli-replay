# Objective

Support in-place redaction: `clirec redact session.clirec` (no `-o`) rewrites the file in place. Add end-to-end integration tests with real `.clirec` fixture data.

# Implementation Plan

- When no `-o` flag: read file, redact to temp file, rename over original (atomic)
- Use `tempfile.NamedTemporaryFile` in same directory for safe rename
- Add fixture `tests/fixtures/sensitive.clirec` with username/hostname/path in event data
- Integration test: record-like fixture in, verify redacted output

# Acceptance Criteria

- [x] `clirec redact file.clirec` redacts the file in place
- [x] In-place uses atomic write (temp file + rename)
- [x] Original file is not corrupted if process is interrupted
- [x] `clirec redact file.clirec -o other.clirec` still writes to separate file
- [x] Integration test with fixture verifies username, hostname, home path are all replaced
- [x] Idempotent: running redact twice produces same output
