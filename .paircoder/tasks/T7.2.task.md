# Objective

Establish a quality notes convention for archived recordings. Each recording gets a `.notes.md` sidecar file documenting quality metrics and session metadata. The `clirec process --verify` command auto-generates notes with measured metrics.

# Acceptance Criteria

- [ ] `~/test-store/production/recordings/CONVENTION.md` is created documenting the naming and notes format
- [ ] Each recording can have a `.notes.md` sidecar file (e.g., `video3-session1-v3.notes.md`)
- [ ] Notes template includes: date, CC version, terminal dimensions, split count, pass/fail status, description of issues
- [ ] `clirec process --verify` auto-generates a `.notes.md` file alongside the output with measured metrics from verification
- [ ] Notes file is written by verify.py alongside the verified output
- [ ] Tests verify notes file is created when `--verify` is used
- [ ] Tests verify notes file contains required template fields (date, dimensions, split count, pass/fail)
- [ ] Tests verify notes file is not created when `--verify` is not used

# Dependencies

- T7.1 (Recording archive with timestamped copies) -- archive directory structure must exist
