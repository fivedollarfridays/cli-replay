# Objective

Replace all `2>/dev/null || true` patterns in `video3-reset.sh` with proper error handling, retry logic, and post-reset verification. The script should never silently swallow failures.

# Acceptance Criteria

- [ ] All `2>/dev/null || true` patterns in `video3-reset.sh` are replaced with proper error handling
- [ ] Each Trello API call result is logged (success/failure with response details)
- [ ] Trello API calls use retry with exponential backoff: 3 attempts at 2s, 4s, 8s intervals
- [ ] After all reset operations, a post-reset verification step confirms each card is in the Planned list
- [ ] Post-reset verification confirms each acceptance criterion checkbox is actually unchecked
- [ ] Script exits non-zero with a clear error message if any step fails after retries
- [ ] Tests verify retry logic triggers on transient failures
- [ ] Tests verify post-reset verification catches cards not in expected state
- [ ] Tests verify script exits non-zero on unrecoverable failure

# Dependencies

None (test-store script change, no code dependencies)
