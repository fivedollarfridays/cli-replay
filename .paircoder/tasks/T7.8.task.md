# Objective

Enhance the `--verify` mode in verify.py to play Claude Code (CC) sections at a slower speed (2x) with more snapshots (10 per section), while shell sections continue at 50x speed. This catches visual defects in the CC UI that fast playback misses.

# Acceptance Criteria

- [ ] When `--verify` is used with a config file containing `cc_ranges`, CC sections play at 2x speed
- [ ] CC sections take 10 snapshots per section (increased from default)
- [ ] Shell sections continue to play at 50x speed with the existing snapshot count
- [ ] The config file's `cc_ranges` field is passed to `verify_recording()` to identify CC vs shell sections
- [ ] verify.py accepts the CC range configuration and adjusts playback speed accordingly
- [ ] Tests verify that CC sections use slower speed (2x) when cc_ranges config is provided
- [ ] Tests verify that shell sections still use fast speed (50x) regardless of cc_ranges
- [ ] Tests verify that more snapshots are taken during CC sections
- [ ] Tests verify default behavior (no cc_ranges) is unchanged
