# Objective

Add terminal size verification to `video3-preflight.sh` that checks `tput cols` and `tput lines` against expected dimensions. If recording inside tmux (T7.3), also verify tmux pane dimensions match. Fail fast with a clear error message if dimensions are wrong.

# Acceptance Criteria

- [ ] `video3-preflight.sh` checks `tput cols` against the expected width (e.g., 99)
- [ ] `video3-preflight.sh` checks `tput lines` against the expected height (e.g., 25)
- [ ] If inside a tmux session, tmux pane dimensions are also verified
- [ ] Dimension mismatches produce a clear error message showing expected vs actual values
- [ ] Script exits non-zero on dimension mismatch (fail fast)
- [ ] Expected dimensions are configurable (variables at top of script or passed as arguments)
- [ ] Tests verify preflight passes when dimensions match
- [ ] Tests verify preflight fails with clear error when dimensions do not match

# Dependencies

- T7.3 (Record inside tmux with dimension lock) -- tmux dimension verification logic
