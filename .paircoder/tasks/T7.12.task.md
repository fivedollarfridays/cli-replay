# Objective

Add a `clirec compare <file1> <file2>` CLI subcommand that compares two recordings by taking snapshots at matching timestamps via tmux and flagging visual differences. Once a clean take exists, future takes can be validated against it as a golden reference.

# Acceptance Criteria

- [ ] `clirec compare <file1> <file2>` subcommand exists
- [ ] Takes N snapshots of each recording at matching timestamps using tmux capture
- [ ] Compares snapshots using simple text diff of tmux capture output
- [ ] Reports: total matching frames, differing frames, and diff content for each differing frame
- [ ] Output clearly identifies which timestamps have differences
- [ ] Exit code is 0 when recordings match, non-zero when differences are found
- [ ] Works with processed .cast files (asciinema format)
- [ ] Tests verify matching recordings produce zero diffs
- [ ] Tests verify differing recordings produce correct diff output
- [ ] Tests verify report format includes frame counts and diff content

# Dependencies

- T7.11 (Pipeline command) -- compare builds on the full pipeline workflow
