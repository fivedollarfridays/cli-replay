# Objective

Expand `video3-preflight.sh` with additional checks: Claude Code version verification, Trello card field presence in task files, system load average, archive disk space, and script file syntax validation.

# Acceptance Criteria

- [ ] Preflight checks `claude --version` output against a pinned version string
- [ ] Preflight verifies `trello_card` field is present in all task files referenced by the session
- [ ] Preflight checks system load average and warns if above 3.0
- [ ] Preflight checks available disk space in the archive directory and warns if low
- [ ] Preflight runs script file syntax validation by dry-run parsing via `python3 -c "from cli_replay.script_feeder import parse_script; parse_script('<script-file>')"`
- [ ] Each check produces a clear pass/warn/fail message
- [ ] Script exits non-zero if any hard-fail check fails (version mismatch, missing trello_card, syntax error)
- [ ] Script produces warnings but continues for soft checks (load average, disk space)
- [ ] Tests verify each individual check detects its failure condition
- [ ] Tests verify script exits non-zero on hard-fail conditions
