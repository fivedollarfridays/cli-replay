# Objective

Create `redact()` main function — reads a `.clirec` file, applies redactions to all events, writes to output. Follows the `reflow()` pattern.

# Implementation Plan

- Add `redact(*, filepath, output)` to `redact.py`
- Read header with `read_header()`, write unchanged
- Iterate events with `iter_events()`, apply `_redact_event()` to each
- Write redacted events with `write_event()`
- Call `_build_replacements()` internally
