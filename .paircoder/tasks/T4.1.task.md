# Objective

Create `_build_replacements()` in `cli_replay/redact.py` — a pure function that detects username, hostname, and home path from the environment and returns an ordered list of (pattern, replacement) tuples.

# Implementation Plan

- Create `cli_replay/redact.py` with `_build_replacements()` function
- Detect: `os.environ.get("USER")`, `socket.gethostname()`, `os.environ.get("HOME")`
- Return list of `(old, new)` tuples ordered longest-first (home path before username)
- Skip any value that is empty or None

# Acceptance Criteria

- [x] `_build_replacements()` returns list of `(str, str)` tuples
- [x] Home path replaced with `/home/user`, username with `user`, hostname with `host`
- [x] Ordered longest-first to prevent partial replacements
- [x] Skips empty/None env values gracefully
- [x] Tests cover: normal case, missing USER, missing HOSTNAME, missing HOME, all missing
