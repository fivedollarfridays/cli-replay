# Objective

Ensure no recording is ever lost by automatically archiving existing files before they are overwritten. Create a `~/test-store/production/recordings/` directory structure and add archive-before-overwrite logic to both `clirec process` and `clirec record`.

# Acceptance Criteria

- [ ] `~/test-store/production/recordings/` directory is created if it does not exist when archiving
- [ ] Before `clirec process` writes its output file, if the output file already exists, a timestamped copy is saved to the archive directory (e.g., `video3-session1-20260318-2145.clirec`)
- [ ] Before `clirec record` writes its output file, if the output file already exists, a timestamped copy is saved to the archive directory
- [ ] Timestamp format in archive filenames is `YYYYMMDD-HHMM`
- [ ] The original file content is preserved exactly in the archive copy (byte-for-byte)
- [ ] Archive function is extracted as a reusable helper (not duplicated between process and record)
- [ ] Tests verify archive copy is created when output file exists
- [ ] Tests verify no archive copy is created when output file does not exist
- [ ] Tests verify timestamp format in archive filename
- [ ] Tests verify original file content is preserved in archive
