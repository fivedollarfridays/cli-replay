# Objective

Add `clirec process` subcommand. Takes a recording file and a YAML config path.
Loads config, runs `process_recording()`, writes to config's output path.

## Usage

```bash
clirec process recording.clirec --config recording.process.yaml
```

Output path comes from the config file — enforces reproducibility.
