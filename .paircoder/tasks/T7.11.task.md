# Objective

Add a `clirec pipeline --config <yaml>` CLI subcommand that chains the full recording workflow: archive previous, preflight, record (inside tmux), check-quality, coalesce (if needed), process, verify, and report. If any step fails, the pipeline stops, logs the failure reason, preserves everything in the archive, and auto-generates failure notes.

# Acceptance Criteria

- [ ] `clirec pipeline --config <yaml>` subcommand exists
- [ ] Pipeline executes steps in order: archive -> preflight -> record (tmux) -> check-quality -> coalesce (if needed) -> process -> verify -> report
- [ ] Config YAML extends the process config with additional fields: `preflight_script`, `record_script`, `dimensions` (width/height), `archive_dir`
- [ ] If any step fails, the pipeline stops immediately
- [ ] On failure: the failure reason is logged, all artifacts are preserved in the archive directory, and a failure notes file is auto-generated
- [ ] Coalesce step runs only if check-quality reports split sequences
- [ ] Final report summarizes all step results (pass/fail/skip for each step)
- [ ] Tests mock each pipeline step and verify the chain executes in correct order
- [ ] Tests verify pipeline stops on step failure
- [ ] Tests verify archive and failure notes are created on failure
- [ ] Tests verify coalesce is skipped when quality check passes
