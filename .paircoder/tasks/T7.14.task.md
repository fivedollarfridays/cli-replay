# Objective

Add a `clirec validate-sequences <file>` CLI subcommand that parses a raw recording and confirms every opened escape sequence is properly closed within the same event. Reports total sequences, incomplete sequences, and split sequences.

# Acceptance Criteria

- [ ] `clirec validate-sequences <file>` subcommand exists and accepts a recording file path
- [ ] Validates CSI sequences are complete (introduced by `\x1b[`, terminated by a letter)
- [ ] Validates DCS sequences are complete (introduced by `\x1bP`, terminated by `\x1b\\`)
- [ ] Validates OSC sequences are properly terminated (introduced by `\x1b]`, terminated by `\x07` or `\x1b\\`)
- [ ] Validates synchronized update pairs: each `\x1b[?2026h` has a matching `\x1b[?2026l` within the same event
- [ ] Reports: total sequence count, incomplete sequence count, split sequence count
- [ ] Exit code is 0 when all sequences are valid, non-zero when issues are found
- [ ] Output lists each problematic event with its index and the incomplete/split sequence details
- [ ] Tests verify correct detection of incomplete CSI sequences
- [ ] Tests verify correct detection of incomplete DCS sequences
- [ ] Tests verify correct detection of unterminated OSC sequences
- [ ] Tests verify correct detection of unmatched synchronized update pairs
- [ ] Tests verify clean recording produces zero issues

# Dependencies
