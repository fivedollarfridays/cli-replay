# Objective

Create a `clirec record-tmux` CLI subcommand (or wrapper) that launches a tmux session at specified dimensions, hides the status bar, and runs `clirec record` inside it. This guarantees consistent terminal dimensions across recording sessions.

# Acceptance Criteria

- [ ] `clirec record-tmux` subcommand exists and accepts `-x W -y H` arguments for width and height
- [ ] Subcommand launches a new tmux session at the specified dimensions
- [ ] Tmux status bar is hidden during recording (set-option status off)
- [ ] `clirec record` runs inside the tmux session with all passed arguments forwarded
- [ ] After tmux session creation, pane dimensions are verified to match the requested size
- [ ] If tmux is not installed or not available, command exits with a clear error message and non-zero exit code
- [ ] If dimension verification fails, command exits with a clear error message and non-zero exit code
- [ ] Tests verify tmux session is created at the correct size (mock or integration)
- [ ] Tests verify error handling when tmux is not available
- [ ] Tests verify dimension mismatch detection

# Dependencies

None (can be done in parallel with T7.1 and T7.2)
