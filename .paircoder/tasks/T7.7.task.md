# Objective

Add a `clirec coalesce <file> -o <output>` CLI subcommand that merges output events occurring within 5ms of each other into single events. This post-processing step fixes split escape sequences without re-recording.

# Acceptance Criteria

- [ ] `clirec coalesce <file> -o <output>` subcommand exists
- [ ] Merges consecutive output events that are within 5ms of each other into a single event
- [ ] Preserves event ordering after merging
- [ ] Does NOT merge across event type boundaries (input events are never merged with output events)
- [ ] Events more than 5ms apart remain as separate events
- [ ] The merged event uses the timestamp of the first event in the group
- [ ] Output file is a valid recording in the same format as input
- [ ] Reuses split detection logic from T7.6 where applicable
- [ ] Tests verify that split events within 5ms are merged correctly
- [ ] Tests verify that events more than 5ms apart are not merged
- [ ] Tests verify that input events are not merged with adjacent output events
- [ ] Tests verify event ordering is preserved after coalescing

# Dependencies

- T7.6 (Split-sequence quality gate) -- reuses split detection logic
