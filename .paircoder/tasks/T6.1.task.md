# Objective

Create `cli_replay/process.py` with `ProcessConfig` dataclass and `load_config()` YAML loader.
This is the reproducibility anchor — the config file defines CC time ranges and is committed
alongside the recording.

## Config Format

```yaml
input: /tmp/video3-session1.clirec
output: /tmp/video3-session1-final.clirec
cc_ranges:
  - [23.1, 201.4]
  - [273.9, 464.7]
  - [536.6, 682.5]
  - [738.3, 767.7]
```

# Acceptance Criteria

- [ ] `ProcessConfig` dataclass: `input_path: str`, `output_path: str`, `cc_ranges: list[tuple[float, float]]`
- [ ] `load_config(path: str) -> ProcessConfig` reads YAML and returns populated config
- [ ] Raises `ValueError` if `input` or `output` keys missing
- [ ] Raises `ValueError` if `cc_ranges` entries are not 2-element lists
- [ ] Helper `is_in_cc_range(t: float, cc_ranges: list[tuple[float, float]]) -> bool`
- [ ] All tests pass with 100% coverage of new code
